# SNAB — Redefine Your Wardrobe

SNAB is a premium, beautifully crafted landing page for a modern clothing brand. The project focuses on high-end typography, dynamic 3D CSS art, seamless animations, and a rich dark-themed aesthetic with vibrant green neon accents.

## 🚀 Features

- **Custom Cursor & Interactions**: A custom dual-element cursor that reacts to hover states on interactive elements.
- **Dynamic 3D Visuals**: Leveraging advanced CSS transforms for floating 3D product cards and rotating wireframe cubes.
- **Scroll-Triggered Animations**: Elements smoothly reveal themselves (`reveal`, `reveal-l`, `reveal-r`) using the Intersection Observer API for performance-friendly scroll animations.
- **High-End Typography**: Combining *Cormorant Garamond* for sophisticated headings and *DM Sans* for clean, modern body text.
- **Responsive & Dynamic Design**: Smooth transitioning navigation bars, animated marquees, and interactive grids.
- **Zero Dependencies**: Entirely built with Vanilla HTML, CSS, and lightweight JavaScript.

## 🛠️ Technologies Used

- **HTML5**: Semantic and clean structural layout.
- **CSS3**: Extensive use of CSS variables, Grid/Flexbox layouts, keyframe animations, blurs, and 3D transforms.
- **JavaScript (Vanilla)**: For mouse tracking, custom cursor logic, scroll listeners, and the Intersection Observer logic.
- **SVG**: Inline SVG graphics for icons and dynamic card illustrations to keep the page lightweight and resolution-independent.

## 🌐 How to Run

1. Clone or download this project to your local machine.
2. Navigate to the project directory.
3. Open `index.html` in any modern web browser (Google Chrome, Firefox, Safari, Edge).

*No build tools or local servers are required to view this project!*

## 🎨 Design Philosophy

The project leans heavily on glassmorphism elements, high-contrast dark themes (`#020804`), and a signature neon green color (`#00E87A`) to create a "wow" factor upon first glance. Micro-animations and hover effects encourage user interaction and make the interface feel alive.
